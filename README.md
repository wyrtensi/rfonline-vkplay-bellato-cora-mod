Полная двусторонняя визуальная и звуковая замена рас **Кора** и **Беллато** для клиента RF Online 4.75 (Innova / 4game / VK Play).

Играйте за персонажа Коры с бронёй, скелетом, анимациями, свечениями, иконками и звуками Беллато — и наоборот.

Поставляется как **автономное приложение `RFOnline_Cora_Bellato_Mod.exe` с графическим интерфейсом** — Python и `.bat` скрипты не нужны.

---

## Быстрый старт

1. Скачайте `RFOnline_Cora_Bellato_Mod.exe` из раздела **[Releases](../../releases)**.
2. Запустите двойным кликом.
3. Проверьте путь к игре (программа находит папку автоматически, либо укажите вручную через **Обзор**).
4. Нажмите **Полная установка / Переустановка**.
5. Дождитесь сообщения `УСТАНОВКА УСПЕШНО ЗАВЕРШЕНА` в окне журнала.
6. Запускайте игру через лаунчер.

> [!TIP]
> **После любого обновления игры** достаточно открыть `.exe` и нажать **1-Click Восстановление** — мод восстанавливается из кэша за 1-2 секунды.

## Графический интерфейс

Функции интерфейса:

| Кнопка | Действие |
|--------|----------|
| **1-Click Восстановление** | Мгновенно восстанавливает мод из `_ModCache/` после обновления клиента или «Починки игры» в лаунчере. |
| **Полная установка / Переустановка** | Создаёт резервную копию в `_ModBackup/`, синтезирует скелеты, свапает меши, текстуры, эффекты, звуки, спрайты и формирует кэш. |
| **Проверить целостность** | Диагностика клиента: контрольные размеры мешей, скелетов, шлемов, крыльев ЧВ. |
| **Откатить к оригиналу** | Полный возврат всех файлов в заводское состояние из резервной копии. |

Программа автоматически находит папку RF Online на дисках N:, C:, D:.
Состояние мода отображается в статусной строке: **мод активен**, **оригинальная игра** или **папка не найдена**.

## Что заменяет мод

| Категория | Описание |
|-----------|----------|
| **3D-модели и текстуры** | Все сеты брони с 1 по 75 ур., включая Белую броню, Реликты, Мастер, Палмас 55, Орихаркон 70, Баалзебуб 75, Драконьи доспехи, шлемы, визоры и маски. |
| **Скелеты и пропорции** | Адаптивные скелеты `.bn`, валидные для встроенного валидатора костей RF_Online.exe: BelFemale (25 костей), CorFemale (38 костей), BelMale (30 костей), CorMale (29 костей). |
| **Анимации** | Походка, бег, стойки, боевые стойки, атаки, подбор предметов, прыжки, эмоции. |
| **Плащи и антигравы** | Корректный обмен антигравов и крыльев с привязкой к дамми-узлам (BALL00..BALL03). |
| **Свечения и эффекты** | Свечение брони, выхлоп бустеров, ауры наград ЧВ, эффекты Патриархов, Архонтов и ГМ. |
| **Иконки в инвентаре** | Побайтовый обмен 560 пар DXT1-блоков в `item.spr` (шлемы, торсы, штаны, перчатки, ботинки, плащи). |
| **Ранги и гербы** | Крылья рангов над головой, гербы рас в окне цели через `common.spr`, `pvp.spr`, `charinfo.spr`. |
| **Озвучка и музыка** | Клики по персонажам, боевые выкрики, фоновая музыка баз. |

MAU (мехи Беллато), Анимусы (Коры), магия Тьмы/Света и классовые скиллы 30/40 уровней остаются без изменений.

## Консольный режим (CLI)

Те же действия доступны из командной строки:

```powershell
# Полная установка
.\RFOnline_Cora_Bellato_Mod.exe --apply

# Быстрое восстановление из кэша
.\RFOnline_Cora_Bellato_Mod.exe --restore

# Проверка целостности
.\RFOnline_Cora_Bellato_Mod.exe --verify

# Откат к оригиналу
.\RFOnline_Cora_Bellato_Mod.exe --rollback

# Чистая переустановка
.\RFOnline_Cora_Bellato_Mod.exe --force

# Указать нестандартный путь
.\RFOnline_Cora_Bellato_Mod.exe --game-dir "D:\Games\RF Online" --apply

# Принудительный запуск GUI
.\RFOnline_Cora_Bellato_Mod.exe --gui
```

## Решённые инженерные проблемы

Подробности — в [MODDING_GUIDE.md](docs/MODDING_GUIDE.md) и [FIX_WALKTHROUGH.md](docs/FIX_WALKTHROUGH.md).

**Валидатор скелетов R3Engine** — движок проверяет точное количество костей при загрузке расы. Простое переименование файлов приводит к крашу. Реализован синтез гибридных скелетов: добавление фиктивных Dummy Nub-костей или слияние второстепенных.

**Невидимые штаны и шлемы Палмас 55** — ID мешей Беллато не совпадают с ID Коры в архивах RFS. Внедрена виртуальная трансляция ID внутри VFS.

**Орбитальные сферы бустеров** — требуют согласования дамми-узлов в геометрии `.MSH`, ключевых кадров траектории и эмиттеров частиц в `.EFF`.

**Своп значков рас** — гербы рас загружаются из недокументированных блоков DXT1 в конце файла `common.spr`. Пропатчены все 4 копии файла.
